## Iteration 1: s7-opening (KEEP)

- **Hypothesis:** S7 (QWK 0.146) gave level 4 to every context note except one. The editors give level 2 to a note whose only station facts are opening dates (of the station, its platforms or its line section), and level 3 to a note where a network-wide renovation takes most of the space. The baseline levels do not say this.
- **Change:** only the S7 question. The question now tells Jev to test each station fact: "could the same sentence be written about most other stations?" Level 2 names opening dates of platforms and line sections, standard tiling styles and renovations. Level 3 adds "one specific fact next to generic facts". Level 4 names examples of station-only facts. All example sentences are new (not dev texts).
- **Result (dev):** primary 0.501 -> 0.600. S7 0.146 -> 0.863 (exact 0.86, bias -0.14). Side effects in the same request: S2 0.633 -> 0.652, S5 0.638 -> 0.593, native 0.295 -> 0.247. Tell F1 0.692 (same), planted recall 7/15 (same).
- **Decision:** KEEP (+0.099, guard holds).
- **Learned:** S7 has only 14 dev items (7 pairs, EN and FR always have the same label), so one pair moves S7 QWK by a large amount. The level text was written from the dev errors (Michel-Ange-Auteuil, Concorde); expect less gain on test. Campo-Formio (label 4, an unusual event at opening) now gets 3, so "opening" wording pushes some good notes down. A change to one Score in a request also moves other Scores in the same request (S5 -0.045), so compare all dims after each wording change.

## Iteration 2: s4-wordy (KEEP, small margin)

- **Hypothesis:** S4 (QWK 0.468) misses most label-3 items (10 of 17 errors are label 3, Jev 4). Many are FR notes where the editors marked wordy periphrasis (a long verb phrase where one verb says the same), which the filler_phrase Noul does not name.
- **Change:** only the filler_phrase Noul (S4 level 3), for all requests that ask it. It now lists three kinds: intensifier or signpost, persistence or metro-opening comparison, and wordy periphrasis, with new example phrases ('carried out the construction of', « procède à l’inauguration de », « exerce ses fonctions de maire », « au sein de »). Explicit true/false criteria: deleting or shortening the phrase keeps every fact.
- **Result (dev):** primary 0.600 -> 0.612. S4 0.468 -> 0.514 (Vavin FR now level 3; Pont-Neuf FR now 4, correct). Side effects in the same request: S2 0.652 -> 0.719 (3 items better, 1 worse), S1 0.246 -> 0.215 (Gare de l'Est FR 4 -> 3), native 0.247 -> 0.308. Tell F1 0.692 -> 0.654 (lost t2 on Étienne Marcel EN, new t4 false positive on a planted unit). Planted recall 7/15 (same).
- **Decision:** KEEP by the rule (+0.012, planted recall holds). The direct S4 part is about +0.007 of the mean; the rest is S2 side-effect movement, so the margin is mostly noise. Tell F1 fell; watch it in the next iterations.
- **Learned:** the periphrasis wording fixed only 1 of the 7 FR label-3 misses (Tolbiac, Michel-Ange-Auteuil, Saint-Placide, Palais-Royal FR still get 4). The editors' FR label-3 cases are not clear filler; they look like loose phrasing ("comme à la station voisine", « pour cet arrêt »). A Noul cannot see this well. Also the Oberkampf context pair (label 2/3) still gets level 1 from deletable_sentence: the editors do not treat a sentence that only judges the subject as a whole empty sentence, which conflicts with the rubric text.

## Iteration 3: s5-referent (DISCARD)

- **Hypothesis:** S5 misses 3 context pairs that the editors gave level 1 (Michel-Ange-Auteuil, Villejuif–Gustave Roussy, Simplon FR). In each, a definite noun phrase has its referent only in `etymology` ("this crossing", "the institute", "the pass"). Jev reads `etymology` in the same state, so the S5 Score does not see the problem. A separate Noul that asks only this, with a code cap to S5 level 1, should catch them.
- **Change:** one new Noul `orphan_reference`, asked only for context units, with true/false criteria and new example phrases. In `assess`, `orphan_reference >= 0.5` sets S5 to level 1.
- **Result (dev):** primary 0.612 -> 0.595. S5 0.593 -> 0.520 (bias -0.03 -> -0.38): 9 label-3 context notes went to level 1. Side effect S2 0.719 -> 0.674. Tell F1 0.654 -> 0.679. Planted recall 7/15 (same).
- **Decision:** DISCARD (primary falls).
- **Learned:** the Noul does not separate the classes. On the 38 context units, the label-1 notes score 0.62–0.92, and label-3 notes score up to 0.84 (Campo-Formio 0.80/0.84, Place d'Italie 0.75/0.79, Simplon EN 0.86 with label 3). No threshold helps. The editors are not consistent here either: Simplon EN ("the pass") is label 3 and Simplon FR (« le col ») is label 1. The S5 level-1 rule for context notes is too uncertain in the labels to tune against; try other dimensions next.

## Iteration 4: s1-chain and s1-stop (DISCARD)

- **Hypothesis:** S1 (QWK 0.215, 10 errors in 46) has two error groups. (a) Jev gives level 3 to complete compound names whose second part is a subtitle or added street (Reuilly-Diderot EN/FR, Gare de l'Est EN/FR, La Défense EN): it seems to want the street's own origin explained. (b) The editors give FR level 2 or 3 where the first sentence names the source only by a generic description (La Défense FR « au quartier d'affaires », Chevilly-Larue FR « à la commune où elle se trouve », Ourcq FR « le canal voisin »).
- **Change:** only the S1 question for etymology units. s1-chain: the chain may stop at a named street, district, town or structure; a subtitle that names a street is complete; a generic description without the name word is a missing link (level 2), or level 3 when the name word comes only in a later sentence. s1-stop (narrower second try of the same change): only the "chain may stop at a named street or place; a subtitle naming a street is explained" part. New example sentences.
- **Result (dev):** s1-chain: primary 0.612 -> 0.589, S1 0.215 -> 0.094 (exact 0.78 -> 0.80), S2 0.719 -> 0.679. s1-stop: primary 0.612 -> 0.592, S1 0.215 -> 0.069 (exact 0.78 -> 0.85, bias +0.11), S2 0.725, native 0.333, tell F1 0.692. Planted recall 7/15 in both.
- **Decision:** DISCARD both (primary falls).
- **Learned:** S1 QWK is not a useful target in its present form. 41 of 46 labels are 4 (3 at level 3, 2 at level 2), so QWK depends almost only on the 2 label-2 items (La Défense FR, Ourcq FR). s1-stop raised exact agreement from 0.78 to 0.85 and still lowered QWK, because La Défense FR went from 3 to 4. The generic-description rule in s1-chain also fails on the labels: Kremlin-Bicêtre FR « doit son nom à la commune » has label 4 while La Défense FR « au quartier d'affaires » has label 2, and Jacques Bonsergent EN ("after the square honouring...") has label 4. The editors' FR S1 downgrades do not follow a rule that a question can state. Do not tune S1 further on dev; a change to the metric for skewed dims (for example exact or within-1 for S1) is a harness decision, not a config change.

## Iteration 5: s6-generic and s6-unnamed (DISCARD)

- **Hypothesis:** S6 (QWK 0.563) loses most of its kappa on one pair: Ourcq etymology has label 1 (FR « le canal voisin » drops the name that EN gives as "the canal of that name"), and Jev gives level 4. That one item is about half of the weighted disagreement. The other misses are label-3 pairs (a minor gloss in one version) that get level 4. The parity Nouls do not count a name that one version replaces with a generic description, and the `false` text even lists « comme la rue voisine » as acceptable.
- **Change:** only the station pair request. s6-generic: fr_missing and en_missing also count a thing that one version names and the other describes only generically; the `false` text keeps « comme la rue voisine » only when the name is in the same sentence. s6-unnamed (second variant of the same change, base parity Nouls): a separate Noul `unnamed_place` that compares the named places of both versions; `>= 0.5` sets S6 to level 1. New example phrases (abbey of Saint-Maur, the Marne).
- **Result (dev):** both variants: primary 0.612 -> 0.615, S6 0.563 -> 0.584 (exact 0.82 -> 0.84). All unit dimensions unchanged (pair request only). Tell F1 0.654, planted recall 7/15 (same).
- **Decision:** DISCARD both (+0.003, below the 0.01 rule).
- **Learned:** the gain is not on the target item. Ourcq fr_missing stayed at 0.24 (was 0.21); `unnamed_place` ranks Ourcq first of 44 station pairs, but only at 0.36, and the next pairs are at 0.10–0.17. A threshold at 0.3 would fit exactly this one dev item, so it was not tried. The +0.021 on S6 comes from Saint-Placide context (label 4): fr_missing fell from 0.56 to 0.41 (s6-generic, because of the same-sentence rule) or moved below 0.5 as a side effect of the added Noul (s6-unnamed), so it went from level 3 to 4. The label-3 "minor gloss" pairs have missing scores 0.06–0.37, mixed with the label-4 pairs (0.05–0.41), so no parity Noul threshold separates level 3 from level 4. New helper `lab/dump-answers.ts <config>` prints the cached raw answers with the editor labels for every dev unit and pair; use it before writing a change. With it, two cheap checks also failed: a per-dimension offset on the raw Score (S2, S3, S5, S7; no offset improves QWK except noise on S1), and a different S5 2/3 cutoff with the code caps kept (best = current 1.5).

## Iteration 6: s2-other (DISCARD)

- **Hypothesis:** Several FR label-3 S2 items with high Jev S2 (La Défense FR « au quartier d'affaires », Ourcq FR « le canal voisin ») give a place only by a common noun where the EN note names it. Jev sees only one locale, so it cannot know that a name was available. Give the other-language note in the state and let the S2 level-3 text use it. (The same two FR items are the S1 label-2 items, so S1 could move as a side effect.)
- **Change:** one state-format change for station units: `other_version` (the same note in the other language) is added to the state, and the S2 question says to use it only to see which names were available. Level 3 adds "a place, building or institution only by a common noun while `other_version` gives its name"; level 4 adds that each such name is also in `text`. New example phrases.
- **Pre-check (offline, no new Jev calls):** before this, I checked two code-only options on the cached answers. (a) S5 length caps: a grid over the level-1 cap (35 words or none), the level-2 cap (19–27 words) and the 2/3 cutoff. The current 35/25/1.5 is within noise of the best (0.593 vs 0.600–0.615 only with caps tuned to single items). (b) Config `s4-del2`: deletable_sentence gives S4 level 2 instead of level 1 (Oberkampf context has labels 2/3). Primary 0.612 -> 0.610, S4 0.514 -> 0.501. Not kept.
- **Result (dev):** primary 0.612 -> 0.574. S2 0.719 -> 0.608 (bias +0.07 -> -0.04): new level-3 false positives on Cadet EN (to 2), Rue des Boulets EN, Chevilly-Larue FR, Saint-Placide context FR (« comme la rue voisine » while EN names Rue de Vaugirard). S1 0.215 -> 0.279 as a side effect. S3 0.815 -> 0.780, S5 0.593 -> 0.575, S7 0.863 -> 0.696 (Campo-Formio FR 4 -> 2). Tell F1 0.654 -> 0.714 (real 0.839, fn 0). Planted recall 7/15 (same).
- **Decision:** DISCARD (primary falls).
- **Learned:** an extra state field changes every Score in the request, not only the question that names it (S3, S5, S7 all moved). The "name in the other version" rule flags too much: the editors accept « comme la rue voisine » and « la commune où elle se trouve » as precise enough. Tell F1 rose with the extra state; if a tell-only request is ever split out, the other-language note may help tells. The S5 caps and the S4 mapping are already near their best on dev; code-only remapping of cached answers is not a source of a 0.01 gain.
