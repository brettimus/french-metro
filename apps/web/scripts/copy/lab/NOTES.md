## Iteration 1: s7-opening (KEEP)

- **Hypothesis:** S7 (QWK 0.146) gave level 4 to every context note except one. The editors give level 2 to a note whose only station facts are opening dates (of the station, its platforms or its line section), and level 3 to a note where a network-wide renovation takes most of the space. The baseline levels do not say this.
- **Change:** only the S7 question. The question now tells Jev to test each station fact: "could the same sentence be written about most other stations?" Level 2 names opening dates of platforms and line sections, standard tiling styles and renovations. Level 3 adds "one specific fact next to generic facts". Level 4 names examples of station-only facts. All example sentences are new (not dev texts).
- **Result (dev):** primary 0.501 -> 0.600. S7 0.146 -> 0.863 (exact 0.86, bias -0.14). Side effects in the same request: S2 0.633 -> 0.652, S5 0.638 -> 0.593, native 0.295 -> 0.247. Tell F1 0.692 (same), planted recall 7/15 (same).
- **Decision:** KEEP (+0.099, guard holds).
- **Learned:** S7 has only 14 dev items (7 pairs, EN and FR always have the same label), so one pair moves S7 QWK by a large amount. The level text was written from the dev errors (Michel-Ange-Auteuil, Concorde); expect less gain on test. Campo-Formio (label 4, an unusual event at opening) now gets 3, so "opening" wording pushes some good notes down. A change to one Score in a request also moves other Scores in the same request (S5 -0.045), so compare all dims after each wording change.

## Iteration 2: s4-wordy (KEEP, small margin)

- **Hypothesis:** S4 (QWK 0.468) misses most label-3 items (10 of 17 errors are label 3, Jev 4). Many are FR notes where the editors marked wordy periphrasis (a long verb phrase where one verb says the same), which the filler_phrase Noul does not name.
- **Change:** only the filler_phrase Noul (S4 level 3), for all requests that ask it. It now lists three kinds: intensifier or signpost, persistence or metro-opening comparison, and wordy periphrasis, with new example phrases ('carried out the construction of', « procède à l’inauguration de », « exerce ses fonctions de maire », « au sein de »). Explicit true/false criteria: deleting or shortening the phrase keeps every fact.
- **Result (dev):** primary 0.600 -> 0.612. S4 0.468 -> 0.514 (Vavin FR now level 3; Pont-Neuf FR now 4, correct). Side effects in the same request: S2 0.652 -> 0.719 (3 items better, 1 worse), S1 0.246 -> 0.215 (Gare de l'Est FR 4 -> 3), native 0.247 -> 0.308. Tell F1 0.692 -> 0.654 (lost t2 on Étienne Marcel EN, new t4 false positive on a planted unit). Planted recall 7/15 (same).
- **Decision:** KEEP by the rule (+0.012, planted recall holds). The direct S4 part is about +0.007 of the mean; the rest is S2 side-effect movement, so the margin is mostly noise. Tell F1 fell; watch it in the next iterations.
- **Learned:** the periphrasis wording fixed only 1 of the 7 FR label-3 misses (Tolbiac, Michel-Ange-Auteuil, Saint-Placide, Palais-Royal FR still get 4). The editors' FR label-3 cases are not clear filler; they look like loose phrasing ("comme à la station voisine", « pour cet arrêt »). A Noul cannot see this well. Also the Oberkampf context pair (label 2/3) still gets level 1 from deletable_sentence: the editors do not treat a sentence that only judges the subject as a whole empty sentence, which conflicts with the rubric text.
