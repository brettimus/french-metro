# Line 14 name audit

Checked on 19 September 2026. Scope: 21 stations, north to south. The module is `apps/web/src/data/line14.ts`. All legacy station IDs are preserved. English and French text state the same name-origin claims.

## Method and limits

Each station has a direct name explanation and a short context paragraph. Wikipedia station pages were read as secondary references. Municipal, institutional and transport sources were added for the deeper naming steps where available. Biography links are provided in both languages. These sources support naming history, not live travel advice. Opening-year fields are omitted; selected verified dates remain in context text.

The text stops at a supported place-name relationship when the ancient origin is uncertain or outside the evidence. It does not invent ancient personal names for Bercy, Chevilly, L’Haÿ, Villejuif, Clichy, Thiais or Orly. The 2022 IDFM article contains old projected opening dates; only its confirmed naming results are used.

## Checks

- The module has 21 unique IDs. Their order and spelling match the old station list.
- One path contains the complete north-to-south sequence. Its endpoints match the termini.
- Every station has sources, an English explanation, a French explanation and context in both languages.
- Each explanation has 25–55 words; each context paragraph has 30–75 words, counted by whitespace.
- The isolated TypeScript check passed: `apps/web/node_modules/.bin/tsc --noEmit --skipLibCheck --target ES2022 --module ESNext --moduleResolution Bundler apps/web/src/data/line14.ts`.
- The whole-app check was attempted during parallel work. It stopped because `line7.ts` was not yet present. That error is outside this slice.
- The module uses `/illustrations/line-14.png`; the illustration worker owns the image.
