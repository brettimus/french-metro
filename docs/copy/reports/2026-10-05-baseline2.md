# Copy evaluation baseline 2, 2026-10-05

This report gives the second full run of the copy evaluator, after the evaluator fixes listed in section 10 of [the first baseline](2026-10-05-baseline.md) and five decisions from the project owner. No app copy was changed. Read the first baseline for the method, the corpus and the calibration.

- Run directory: `apps/web/scripts/copy/out/baseline2/2026-10-05T09-54-43-300Z/` (not committed)
- Command: `bun apps/web/scripts/copy/evaluate.ts --out apps/web/scripts/copy/out/baseline2 --worst 40`
- Judge: `jev-1.13.0`, `@typesafe-ai/sdk` 0.6.0. Question set `2026-10-05.6` (was `.5`).

S7 spot check (new question, both locales): the context notes for oberkampf, etienne-marcel, vavin, raspail and alesia (all level 1 in the first baseline, all about the namesake) now score level 3 (probability 0.79–0.97). Two test notes for Vavin scored level 1: one paraphrases the etymology, the other only gives the opening date. A third test note with a station-specific fact scored level 4 (probability 1.00).

Tests: new tests cover the "May" month, the T17 patterns in both locales, name folding and the name map, T21 on a shared station, the UI request state (usage, role, siblings) and per-string U2. `bun run test` and `bun run typecheck` pass.
