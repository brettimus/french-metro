## 1. Method

### Rubric

The rubric is [`docs/copy/writing-rubric.md`](../writing-rubric.md). It has:

- 8 project rules (R1–R8) from `types.ts`, the line plans, the reviews and the research notes.
- Judged dimensions: S1–S7 for station notes, L1–L3 for line copy, U1–U3 for UI strings.
- 26 binary tells (T1–T26). T22–T26 are hard failures.
- Deterministic checks (section 4): word counts, sentence length, FR and EN typography, word lists, parity checks.
- Composite (section 5): weighted dimensions, minus 0.05 per soft tell (cap 0.25) and 0.05 per FAIL check (cap 0.20). Bands: ship ≥ 0.85, edit 0.65–0.84, rewrite < 0.65.

### Model and question set

- Judge: Jev `jev-1.13.0` through `@typesafe-ai/sdk` 0.6.0.
- Question set: `2026-10-05.5` in `apps/web/scripts/copy/questions.ts`.
- Each unit gets one request per locale. Each EN/FR pair gets one pair request. Each UI locale gets one request that sees all UI strings together.

S6 is computed in code from the pair Nouls and the FR calque patterns, not from the S6_judged score. The code also caps some scores: S5 drops to level 1 when a note opens with a pronoun, and drops when a sentence is longer than 25 or 35 words. S3 drops to level 2 when the code word lists find T2, T4, T8 or T13.

### Known weak questions

Read these results with care:

- **The calibration gain is partly fitted.** The flagged units were chosen because Jev disagreed with the editors, and some new criteria quote phrases from that same sample. Confirm the questions on a different seed with fresh grades before you give them full weight.
- **The editors disagree with each other on five units:** mairie-de-montreuil S3, simplon S5, jasmin S7, Line 1 summary S3, cadet S2. Full agreement is not possible there.
- **`native` (FR hint):** answers stay between 3.1 and 3.8 and it found 0 of 4 flagged units. Recommended for removal. It does not affect the composite.
- **Station `S6_judged` (hint):** misses both station calques. The code-computed S6 does this job. Recommended for removal.
- **Pair `fr_calque` (hint):** found 2 of 5. It repeats t19 and the code patterns. Recommended for removal.
- **t12 false range:** a false positive on the Line 1 summary, because the summary says "a royal château" and does not name Vincennes. Fix the copy, not the question. In this run t12 fired on all four line summaries that use "from X to Y" (Lines 1, 7, 9, 14).
- **t5, t13, t14, t16:** the calibration sample had no true cases. Do not give these weight until they are tested on bad examples written for the purpose.
- **S4 FR (MAD 0.46) and S5 (0.41 both locales)** are the least reliable score questions.
- **en_missing:** one known false positive (vavin, 0.62).
- **U1 and U2 (UI):** not calibrated against editors. See "UI scores".

### UI scores

UI strings have no "ship" units, but treat this with caution:

- U2 (consistency) is one judgment per locale, applied to every UI string: EN 0.34, FR 0.22 (word_conflict 0.57 for both; verb_mix EN 0.41, FR 0.97). This lowers every UI composite by the same amount. The FR verb_mix result probably points to a real mix of infinitive buttons (« Explorer la ligne ») and other forms, but the question does not say which strings conflict.
- U1 judges a label without its place on the page. Single-word labels that are clear on screen ("Line", "Station", "Terminus", "Branch") get level 1 or 2. The photographer credit "Terrazzo" scores 0.26 because it is a name, not a label.
- With U2 removed and the weights renormalised, the UI mean is EN 0.776 and FR 0.828.

Use the UI results only for specific findings, for example "Featured" / « À découvrir » (vague), "MÉTRO / NAMES" (brand mark), and the plain space before « ? » in « Pourquoi ce nom ? ».

## 6. Formulaic templates

The mandated etymology openings (rule R2) are exempt from T20, but they are still very uniform:

- EN etymology: 137 of 200 open "Called …"; 53 open "Named for …" ("Named for the" 19, "Named for Rue" 12, "Named for Place" 9).
- FR etymology: all 200 open « La station … »; 156 open « La station doit son nom à », 31 « La station porte le nom de ».

Context notes have no mandated opening, but they use a few patterns:

| Pattern | EN | FR |
|---|---|---|
| Opening date clause: "The station opened…" / « La station ouvre… » | 20 | 20 |
| "Opened on/in [date], …" / « Ouverte le/en [date], … » | 24 | 27 |
| Total that open with the opening date | 44 (22%) | 47 (24%) |
| "…with the line's first section" / « avec le premier tronçon de la ligne » | 10 | 11 |
| "The Line N platform…" / « Le quai / Les quais de la ligne N… » | 10 ("The Line 9", "The Line 6") | 16 |
| "The elevated station…" / « La station aérienne… » | 4 | 4 |
| "It remains…" closing sentence | 2 | 0 |

The rubric removed the "Opened in 1900, …" example from S5 because Jev applied it to every note with that opening. The opening date is a fact, so it is not a fault by itself. It becomes a fault when it is the only station fact and the rest of the note is about something else (see Charonne, Jasmin, Rue de la Pompe below).

Sentence counts are also uniform. On every line 72–97% of notes in a field have the same number of sentences (usually 2). Line 9 etymologies are the exception in the other direction: 31 of 37 EN notes and 32 of 37 FR notes are one sentence.
